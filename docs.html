2. System Architecture & Device Compatibility Overview

Why separate GitHub Pages and Google Apps Script?
If HTML files are hosted directly inside Google Apps Script, Google wraps the web page in a sandboxed <iframe>, prompting modern browsers to block microphone access with a not-allowed error. Separating the frontend to GitHub Pages provides a native HTTPS origin, permanently resolving microphone permission restrictions across all modern devices.
1. Frontend (UI)
GitHub Pages (HTTPS)

Executes SpeechSynthesis (US English native voice model) and SpeechRecognition (voice recording and per-word analysis without microphone blocks).

2. Backend API
Google Apps Script

Receives score data payloads in JSON format transmitted from the web interface via asynchronous POST requests.

Step 2

Create and Deploy Google Apps Script (Backend API)

In Google Sheets, go to Extensions → Apps Script, paste the code below, and click Deploy → New deployment → Web app.

1. Description: EchoScore Pronunciation Assessment API
2. Execute as: Me (Your Google Account)
3. Who has access (Crucial!): Anyone 
function doGet(e) {
  return ContentService.createTextOutput("Pronunciation API is running.");
}

function doPost(e) {
  try {
    var params = JSON.parse(e.postData.contents);
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();

    sheet.appendRow([
      new Date(),
      params.className || "",
      params.studentId || "",
      params.studentName || "",
      params.attemptCount || 0,
      params.targetSentence || "",
      (params.completion !== undefined ? params.completion + "%" : "0%"),
      (params.accuracy !== undefined ? params.accuracy + "%" : "0%"),
      params.transcript || ""
    ]);

    return ContentService.createTextOutput(JSON.stringify({ "status": "success" }))
      .setMimeType(ContentService.MimeType.JSON);

  } catch (error) {
    return ContentService.createTextOutput(JSON.stringify({ "status": "error", "message": error.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

Step 4

Deploy Web App to GitHub Pages

  1. 1. Create Repository: Sign in to GitHub → Click the + icon in the top right → New repository. Name it echoscore-app, choose Public, and click Create repository.
  2. 2. Upload HTML File: Click uploading an existing file → Drag and drop the pronunciation.html file downloaded in Step 3 → Click the green Commit changes button.
  3. 3. Enable GitHub Pages: Navigate to Settings → Select Pages in the left menu → Under Branch, switch from None to main (keep directory as /(root)) → Click Save.
  4. 4. Share Live HTTPS Link with Students: Wait about 1 minute and refresh the page. The full URL to share with students will be:
    https://<username>.github.io/echoscore-app/pronunciation.html
