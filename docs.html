Nếu đặt trực tiếp tệp HTML bên trong Google Apps Script, Google sẽ bao bọc trang web trong một khung <iframe> bảo mật, khiến trình duyệt chặn quyền truy cập micro và báo lỗi not-allowed. Bước 2

Tạo và Triển khai Google Apps Script (Backend API)

Trong Google Sheets, chọn Tiện ích mở rộng (Extensions) → Apps Script, dán mã dưới đây và nhấn Triển khai (Deploy) → Ứng dụng web (Web App).

1. Mô tả (Description): API Hệ thống phát âm EchoScore
2. Thực thi dưới dạng (Execute as): Tôi (Me / Your Account)
3. Ai có quyền truy cập (Quan trọng!): Bất kỳ ai (Anyone) 
// 1. Xử lý khi tải trang web (Yêu cầu GET - Dự phòng)
function doGet(e) {
  return ContentService.createTextOutput("Pronunciation API is running.");
}

// 2. Xử lý ghi dữ liệu điểm số (Yêu cầu POST - Ghi chính xác 9 cột vào Google Sheet)
function doPost(e) {
  try {
    // Phân tích dữ liệu định dạng JSON được gửi từ Frontend
    var params = JSON.parse(e.postData.contents);

    // Lấy bảng tính Google Sheet hiện đang được liên kết
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();

    // Lần lượt ghi 9 cột dữ liệu vào dòng mới trong bảng tính
    sheet.appendRow([
      new Date(),                                                           // Cột A: timestamp (Thời gian ghi)
      params.className || "",                                               // Cột B: className (Lớp)
      params.studentId || "",                                               // Cột C: studentId (Mã số HS/SV)
      params.studentName || "",                                             // Cột D: studentName (Họ tên)
      params.attemptCount || 0,                                             // Cột E: attemptCount (Số lần thử)
      params.targetSentence || "",                                          // Cột F: targetSentence (Câu đề bài)
      (params.completion !== undefined ? params.completion + "%" : "0%"),   // Cột G: completion (Độ hoàn thành)
      (params.accuracy !== undefined ? params.accuracy + "%" : "0%"),       // Cột H: accuracy (Độ chính xác)
      params.transcript || ""                                               // Cột I: transcript (Văn bản giọng nói)
    ]);

    // Trả về thông báo thành công cho Frontend
    return ContentService.createTextOutput(JSON.stringify({ "status": "success" }))
      .setMimeType(ContentService.MimeType.JSON);

  } catch (error) {
    // Trả về thông báo lỗi khi có sự cố xảy ra
    return ContentService.createTextOutput(JSON.stringify({ "status": "error", "message": error.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

Bước 4

Đưa Trang web lên GitHub Pages

  1. 1. Tạo Kho lưu trữ (Repository): Đăng nhập GitHub → Nhấn dấu + góc phải → New repository. Đặt tên là echoscore-app, chọn chế độ Public rồi nhấn Create repository.
  2. 2. Tải tệp HTML lên: Nhấn vào dòng uploading an existing file → Kéo thả tệp pronunciation.html vừa tải ở Bước 3 vào → Nhấn nút xanh Commit changes.
  3. 3. Bật GitHub Pages: Vào mục Settings (Bánh răng) → Chọn Pages ở menu trái → Tại mục Branch, đổi None thành main (thư mục giữ nguyên /(root)) → Nhấn Save.
  4. 4. Nhận đường dẫn HTTPS gửi cho học sinh: Đợi 1 phút và tải lại trang. Đường dẫn đầy đủ của học sinh sẽ là:
    https://<username>.github.io/echoscore-app/pronunciation.html
